# Suggested Commands
- `./gradlew :desktop:run` — run the desktop application (requires system Gradle or full wrapper).
- `gradle wrapper` — generate full Gradle wrapper (produces gradle-wrapper.jar) if needed.
- `./gradlew test` — execute unit tests once they are added.
- `./gradlew clean build` — perform a full build and test cycle.
- `./gradlew --stop` — stop any running Gradle daemons when switching tasks.
- General Linux utilities: `ls`, `cd`, `cat`, `grep`, `find`, `git status` for repo inspection.
